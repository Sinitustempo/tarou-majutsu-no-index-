# tarou-majutsu-no-index-
tarou majutsu no index + (psp modded game)
controls 
X = Block (hold)/dodge and dash (tap and move in that direction)
O = special move
triangle = skills 
box = attack (hold down during arial attack to slam enemy to ground)
R trigger = homing attack (push joystick forward and tap trigger)
L trigger = jump
D pad down = taunt 
D pad L/R = Assist character

Online play
go into ppsspp settings 
go to networking
enable network/wlan
change your name under nickname and enable built-in ad hoc server
Add a user name
check forced first connect box at the bottom 
(also under adhoc server address click that I select "Madness Gaming Network")
done
